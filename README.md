# 🍔 Rustic Burger - Landing Page

Uma landing page moderna e responsiva para uma hamburgueria artesanal fictícia chamada **Rustic Burger**.  
O projeto foi desenvolvido com foco em design atrativo, animações suaves e experiência do usuário.

---

## 🚀 Demonstração

> Projeto de página única (One Page) com cardápio dinâmico e animações.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox + Grid + Responsividade)
- JavaScript (ES6)
- GSAP (animações)
- ScrollTrigger (animações ao scroll)
- Lenis (scroll suave)
- Google Fonts

---

## 🎯 Funcionalidades

- Layout moderno inspirado em restaurantes premium
- Navbar fixa com status "Aberto agora"
- Hero section com destaque visual
- Cardápio dinâmico por categorias:
  - Burgers 🍔
  - Hot Dogs 🌭
  - Combos 🎉
  - Pratos do dia 🍽️
- Sistema de troca de categorias via JavaScript
- Carrossel automático de avaliações
- Animações suaves com GSAP
- Scroll fluido com Lenis
- Design totalmente responsivo (mobile-first)
